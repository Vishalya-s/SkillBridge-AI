# SkillBridge-AI

## 🎯 About the Project

SkillBridge-AI is an AI-powered career guidance platform that helps students identify suitable career paths based on their current skills.

It analyzes the user's skills, compares them with the required skills for different careers, shows the skill gap, and provides a personalized learning roadmap.

## ✨ Features

- Career recommendation
- Skill match percentage
- Top career matches
- Matching skills
- Skills to improve
- Personalized learning roadmap
- Career descriptions
- Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Streamlit
